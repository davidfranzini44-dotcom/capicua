# Board assets

All raster assets below were generated using built-in Image Gen, based on the user's selected second mockup. Original generated files are preserved under the Codex generated_images folder. Project assets are optimized WebP files.

- public/images/table-felt.webp: Seamless square dark emerald billiard felt; subtle fine fabric grain; uniform top-down lighting; no objects, text, frame or vignette.
- public/images/table-wood.webp: Seamless warm walnut; horizontal fine grain; medium-dark brown #6b3f22; matte polish; even diffuse lighting; no objects, frame, text, plank seams or perspective.
- public/images/yuly-avatar.webp: Fictional Dominican woman around 30; curly dark hair; natural friendly smile; dark muted green background; realistic centered head-and-shoulders portrait.
- public/images/papo-avatar.webp: Fictional Dominican man around 35; plain dark baseball cap; short beard; natural friendly smile; dark muted green background; realistic centered head-and-shoulders portrait.

UI icons: Phosphor React, https://github.com/phosphor-icons/react (MIT). Existing Rubik and Bungee fonts and code-native domino assets retained.
